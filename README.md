# Smart Remote – IoT Gesture Control for Web Browser

Апаратно-програмний комплекс для жестового керування веб-браузером Google Chrome за допомогою мікроконтролера ESP32 та інерційних сенсорів. Проєкт розроблено як Proof of Concept (PoC) для курсової роботи з дисципліни «Програмування інтернету речей».

## Основні можливості

*   **Природне жестове керування:** Скролінг сторінок (нахили), перемикання вкладок, закриття/відкриття нових вкладок (змахи).
*   **Універсальний медіапульт:** Керування відтворенням (Play/Pause) на популярних сайтах (YouTube, Spotify, SoundCloud) за допомогою безшумного оптичного сенсора.
*   **Динамічне налаштування:** React-панель у браузері для "живої" прив'язки жестів до браузерних команд без перепрошивки пристрою.
*   **Миттєва реакція:** Використання протоколу WebSocket забезпечує передачу команд із затримкою менше 50 мс.
*   **Надійність (Manifest V3):** Вбудований механізм Keep-Alive обходить агресивне енергозбереження сучасних браузерів, запобігаючи засинанню Service Worker-а.

## Стек технологій

**Апаратна частина (IoT):**
*   **Мікроконтролер:** ESP32 (ESP32-WROOM-32D)
*   **Сенсори:** MPU-6050 (6-осьовий гіроскоп/акселерометр), MAX30102 (використовується як високочутливий оптичний тригер)
*   **Розробка:** C++, Arduino Framework, PlatformIO

**Браузерне розширення:**
*   **Стандарт:** Google Chrome Manifest V3
*   **Фреймворк:** Plasmo
*   **Мови/Бібліотеки:** TypeScript, React, HTML/CSS

## Схема підключення

Обидва сенсори (MPU-6050 та MAX30102) підключаються паралельно до однієї шини I2C:

| Модуль | Пін модуля | Пін ESP32 | Призначення |
| :--- | :--- | :--- | :--- |
| **MPU-6050** | VCC | 3V3 | Живлення (3.3V) |
| | GND | GND | Земля |
| | SDA | GPIO 21 (або 8 для S3) | Дані I2C |
| | SCL | GPIO 22 (або 9 для S3) | Синхронізація I2C |
| **MAX30102** | VIN / VCC | 3V3 | Живлення (3.3V) |
| | GND | GND | Земля |
| | SDA | GPIO 21 (або 8 для S3) | Дані I2C |
| | SCL | GPIO 22 (або 9 для S3) | Синхронізація I2C |

## Встановлення та запуск

### Крок 1: Прошивка ESP32
1. Відкрийте папку прошивки у **VS Code** із встановленим розширенням **PlatformIO**.
2. Встановіть вашу Wi-Fi мережу (SSID та пароль) та бажану статичну IP-адресу у файлі `main.cpp`.
3. Підключіть ESP32 через USB та натисніть `Upload` у PlatformIO.
4. Відкрийте Serial Monitor (115200 baud) та переконайтеся, що пристрій підключився до мережі і вивів свою IP-адресу.

### Крок 2: Запуск браузерного розширення
1. Встановіть [Node.js](https://nodejs.org/).
2. Відкрийте термінал у папці розширення (Plasmo) і встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть розширення у режимі розробки:
   ```bash
   npm run dev
   ```
4. Відкриється нове вікно Chrome із завантаженим розширенням. 
5. Натисніть на іконку розширення (пазл у правому верхньому куті), введіть IP-адресу вашого ESP32 та натисніть "Зберегти".

## Алгоритми під капотом

*   **Фільтрація просторових перешкод (Crosstalk Filter):** Алгоритм динамічно блокує розрахунок статичних кутів нахилу (Pitch/Roll) під час інтенсивних змахів (коли сирі дані регістрів гіроскопа > 4000 LSB), запобігаючи хибним спрацюванням скролінгу.
*   **Кінцевий автомат (State Machine):** Використання оптичного сенсора MAX30102 дозволяє розрізняти короткі дотики (для паузи відео) та утримання (для активації керування жестами).
